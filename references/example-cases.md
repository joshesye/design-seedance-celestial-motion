## 案例 01 巨殿奔跑到天阶群像

**结构**：短促比例揭示 + 较长群像建立，两个不同空间之间硬切。

```text
Timestamped prompts
- 0-0.8s：远景广角，低机位仰拍，固定机位伴随极轻微向右跟随。巨型白石雕花基座占左前景，盘龙巨柱与金纹屋顶占右侧和上方；正好一名深色长袍成年人物保持极小比例，在柱间从左向右奔跑，段尾减速停在下一根巨柱前。柱体和屋顶完全静止，衣摆向后飘，柱间薄雾缓慢移动。
- 0.8-3.8s：硬切至高位侧角俯拍的大远景。镜头沿斜向白石长阶极慢前推并轻微下降；约十余名橙、蓝、白色长袍人物分成近中远三组共同向上攀登，步速自然错拍，近组一名橙袍人物抬手示意前方，同伴延迟转肩回应，队形与服色稳定。左侧松针沿风向轻摆，背景暖金云海分层漂移并低频翻滚；结尾众人继续向长阶远方缓行。
```

**锁定**：人物不得离开柱间跑道或阶梯；第一段冷蓝硬侧光，第二段暖金逆光；硬切点禁止场景融合。

## 案例 02 龙首飞瀑到水道跟拍

**结构**：奇观推进 + 沿曲线引导线跟拍。

```text
Timestamped prompts
- 0-1.5s：远景广角深景深，机位在湿润白玉平台左侧，向右前方缓慢推进。红色巨柱盘绕白龙浮雕，白色龙首持续吐水形成瀑布落入云海；红、黑、白三名人物位于栏杆前，红袍人物先缓步靠近栏杆并抬手示意飞瀑，黑袍人物延迟点头，白袍人物转肩跟随视线，三人段尾共同望向龙首。近景地面反射产生轻微视差，瀑布下坠并在落点雾化。
- 1.5-3.5s：硬切至蜿蜒浅水道后方，平视缓慢跟拍。绿、灰、红、黄四名人物按既定前后关系向远处巨门行走；左侧山水壁画、两侧白玉栏杆和曲线水道共同收向消失点。浅水波纹向两侧扩散，倒影低对比扰动，云海越过栏杆但不遮挡道路。
```

**锁定**：第一段三人完成一次克制的指引与回应，第二段四人行走；人物不跨段串场，瀑布不倒流，水道不变形。

## 案例 03 白衣栈道缓步望金门

**结构**：单图一镜到底，轴线极慢推，以短距离缓步建立人物目标。

```text
Timestamped prompts
- 0-4.2s：远景广角深景深长镜头，沿悬空木栈道轴线极慢向前推进。正好一名白袍成年人物背对镜头，位于栈道尽头前方；前方岩壁天宫与巨大矩形金色门扉保持绝对稳定，左前景暗色岩壁和虬结古松形成框景。开头 0.4 秒稳定建立，人物随后沿轴线缓步两步靠近尽头，停步抬头望向金门；白色衣摆、袖口和长发沿同一风向轻摆，松针以更短频率轻动，宫顶双瀑布持续下落，云海分层漂移并低频翻滚。门内金光轻微流动并形成克制辉光；结尾人物稳定停望，镜头减速收在人物与金门严格同轴的构图。
```

**锁定**：一镜到底；正好一人；不推成人物中近景；门洞不漂移、不爆白。

## 案例 04 露台巨桥到灯笼殿内框景

**结构**：外部世界观建立 + 室内横移揭示，两个空间硬切。

```text
Timestamped prompts
- 0-2s：大全景广角深景深，镜头从左下方古典露台缓慢推进。两男一女背对镜头位于栏杆前，左侧人物抬手示意弧形轨道桥，中间人物点头回应，右侧人物向栏杆缓步半步后停住；红柱、绿瓦、栏杆和盆景松组成前景，远处悬浮宫殿群与巨桥完全静止。云海分层漂移，瀑布持续垂落，盆景松针与衣摆同向但不同频轻动。
- 2-5s：硬切至半开放殿内，镜头缓慢向右平移并轻微推进。数排红灯笼、横梁、假山与垂柳从前景形成视差；右侧白玉榻上一名白袍人物保持侧卧姿态，缓慢转头望向圆拱门并抬手整理袖口，段尾放下手臂。视线穿过立柱与圆拱门，揭示云海中央灯火宫殿和稳定垂直光柱。灯笼、帘幔与树梢沿统一风向以不同频率轻摆，远宫移动速度远慢于前景。
```

**锁定**：前景框景不消失，圆门不变形，侧卧人物不坐起，弧桥与远宫不漂移。

## 案例 05 倒置天宫对峙到云桥队列

**结构**：双人克制关系动作 + 高位群像收束。

```text
Timestamped prompts
- 0-2.5s：大远景深景深，平台侧后方极慢前推。红袍人物在左、深蓝袍人物在右，两人背对镜头；红袍人物抬手示意远处倒置天宫，深蓝袍人物延迟侧身并点头回应，随后两人共同望向奇观。倒置天宫维持原方向，瀑布按世界重力向下落入分层漂移的云海；双人间距与左右顺序不变，衣摆同向但不同频微动。
- 2.5-5.1s：硬切至高角度俯拍天宫群，镜头缓慢向前并轻微下降。右前景巨松形成遮挡，白石桥梁和步道串联云海楼阁；众多白袍人物按近中远三组沿桥面缓行，各组步频轻微错开，近组一人停步指向远宫、同伴转肩跟随视线。云雾分层穿过建筑之间，松针轻摆，远山保持稳定；结尾收在完整桥网和宫殿群全景。
```

**锁定**：倒置建筑不翻正；第二段人物全部留在桥面；不做快速无人机俯冲。

## 案例 06 骑兽、圆拱关系戏与悬崖楼阁

**结构**：三段人物引出、关系建立、空间收束；每段硬切。

```text
Timestamped prompts
- 0-2s：大全景深景深，侧后方缓慢推进。白蓝长袍修士稳定骑乘红黑鳞片神兽，位于左侧白玉栏杆边缘；骑手轻收缰绳并抬头望向远宫，神兽缓步两步后停住，衣摆和鬃毛沿同一风向以不同频率飘动。远处悬浮宫城和巨柱保持静止，云海分层漂移并低频翻滚。
- 2-4s：硬切至严格中轴对称的圆拱大殿，沿轴线极慢推进。金色雕花柱、网格穹顶、圆形拱门、浅水方台处于同一轴线；正好两名白袍人物在中央平台保持相对位置，左侧人物抬手递出卷轴，右侧人物延迟伸手接取，段尾共同低头查看。浅水微波、门外云海与瀑布缓慢运动，左右松针轻摆但不做复制镜像。
- 4-5.6s：硬切至悬崖楼阁侧后方，镜头向右缓慢平移并轻微推进。右侧楼阁外挑平台上正好三名白袍人物缓步至观景位后停住，中间人物抬手示意浮岛，左右同伴依次转肩跟随视线。下方瀑布垂落，云海分层穿行于浮岛之间，远处宫殿保持稳定；结尾减速停在楼阁、三人和浮岛形成三层纵深的构图。
```

**锁定**：骑手与神兽不分离；圆拱段正好两人且轴线不漂移；楼阁段正好三人且平台不伸缩。

## 复用方法

1. 根据输入图片数量选择相同段数，不自动把一个案例的全部段落套给单图。
2. 替换人物与建筑时保留景别、主运动、段落节奏和锁定句。
3. 若用户给出新的时长，按比例调整每段，但每段至少留 0.3 秒用于稳定建立或收尾。
4. 用户要求无切镜时，只选择案例中的单个片段；不要把不同空间强行连续化。
5. UI、水印和可识别歌词不是案例骨架，默认删除。
6. 每个有人物的案例段必须保留可见主动作和段尾收势；不要退回“静立 + 衣摆微动”。
