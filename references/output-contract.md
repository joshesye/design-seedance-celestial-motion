## 输出顺序

默认按以下标题输出：

1. `视频提示词`
2. `Timestamped prompts`
3. `UI / Graphic layout`
4. `Color / Lighting`
5. `Music / SFX`
6. `Dialogue / voice-over`
7. `Continuity / Negative constraints`

不要在提示词前写长篇分析。需要解释时，只用一句话说明镜头策略。

## 可替换属性

先提供这一组变量，让用户能替换少量内容生成同类视频：

```text
[总时长]
[镜头段数]
[景别与焦段感]
[机位高度与角度]
[主运镜]
[主体人物与人数]
[服装配色与站位]
[人物开始状态]
[人物主动作]
[人物回应动作]
[人物段尾状态]
[建筑类型]
[关键奇观]
[前景遮挡]
[可见环境元素]
[环境动态]
[时间与天气]
[主光方向]
[色彩逻辑]
[配乐类型]
[环境音]
[对白要求]
[UI要求]
[情绪总纲]
```

固定规则不要放进变量：建筑刚性稳定、人物身份连续、物理运动正确、每段只有一个主运镜。

人物存在时，`人物开始状态`、`人物主动作` 和 `人物段尾状态` 为必填；多人场景还必须填写 `人物回应动作`。衣摆、发丝、呼吸和静立不算人物主动作。画面中没有人物时删除这些人物变量，不凭空添加人物。

## 时间轴段落模板

```text
- [起始时间]-[结束时间]：[景别]，[焦段感/深景深]，[机位位置与俯仰角]，[主运镜及速度]。首帧严格沿用参考图：[前景结构]、[人物开始状态、人数、服色和站位]、[背景建筑与奇观]。镜头运动过程中，[人物主动作]，[同伴延迟回应]，[近景视差]，[远景相对运动]；画面中实际存在的[白云/银河/星星/树叶/瀑布/雾气/水面/衣摆]按[风向、重力、层次和不同频率]持续运动。[主光方向与轮廓光变化]。段尾人物完成[段尾状态]，镜头减速并稳定停在[结束构图]；人物数量、服色、建筑形制和空间轴线保持不变。
```

每个有人物的时间轴段落必须明确“人物开始状态 → 动作过程 → 段尾状态”。远景优先缓步、转肩、点头、抬手示意或停步观察；中近景可用交谈姿态、递物、并肩行走或轮流回应。默认以身体朝向、视线和手势表现交流，无明显口型。

## 环境动态槽位

只写参考图中可见的项目：

- 白云/云海：统一风向，近层快、远层慢，低频翻涌。
- 银河/星河：沿原有弧线或带状方向缓慢流动，不改变天空构图。
- 星星：稀疏、错峰、轻微闪烁，不全屏同步频闪。
- 树叶/松针/树梢：末端分层轻摆，树干与粗枝保持刚性。
- 衣摆/长发/帘幔/灯笼：与植被共享风向，但响应频率、延迟和幅度不同。
- 瀑布/水面/雾气：遵守重力、扰动来源、地形扩散和遮挡关系。

不同场景在下一段开头写：

```text
- [时间]：硬切至[新场景]。重新建立[机位、景别、人物和空间]……
```

不要写“无缝变成”“宫殿逐渐变化为”“云雾中重组”，除非用户明确要超现实形变。

## 色彩与光线模板

```text
- 色彩逻辑：[互补色/冷暖对比/单色系/类比色]。
- Lift：[暗部色相与密度]；Gain：[高光色相与强度]。
- 亮度分布：[S-Curve 强对比/High-key 高调/Low-key 低调]。
- 主光：[时钟方位]的[硬质直射光/柔质散射光/低角度逆光]。
- 空气效果：[体积光、丁达尔、水雾、空气透视]。
- 成像质感：干净数字电影感、自然运动模糊、[轻微/克制] Glow 与 Halation；保持高光细节，不大面积爆白。
```

同一段内不要让主光无原因换边。多场景可在硬切后重新定义光向。

## 声音模板

```text
Music / SFX
- 0-[总时长]：[无歌词空灵女声吟唱/中国风管弦乐/低沉史诗氛围]作为配乐；加入与画面匹配的[风声/瀑布低频/浅水声/衣料声]，环境声低于配乐，无突兀鼓点和现代电子提示音。

Dialogue / voice-over
- 无台词、无旁白、无明显口型动作；人物用身体朝向、视线、手势和点头交流。
```

用户指定台词时，写明说话人、语言、时间段、情绪和口型同步；其余人物不说话。

## UI 与文字

默认：

```text
UI / Graphic layout
- 无字幕、无水印、无标题、无 logo、无播放器 UI。
```

用户明确要求文字时，写清内容、位置、字号关系、颜色、透明度和阴影。不要照抄参考图中的误识别文字。

## 连续性与负面约束

通用版本：

```text
Continuity / Negative constraints
- 严格参考首帧；人物身份、人数、服色、发型、站位和朝向连续；建筑结构、比例、纹样、栏杆、门洞、桥梁和地平线稳定。禁止切镜（多段硬切点除外）、数码变焦、镜头抖动、漂移地平线、建筑融化弯曲、纹样爬动、人物复制消失、换色换装、肢体畸形、滑步穿模、云海棉花化、瀑布倒流、水体悬空、反射复制、突然浅景深、过曝闪烁、游戏 CG 感、塑料材质、字幕、水印和 logo。
- 所有人物动作幅度服从景别，主角先动、同伴延迟回应；禁止全员同频抬手、同步迈步或机械摆动。银河不得旋转成漩涡，星星不得全屏同步频闪，树干和粗枝不得随叶片一起晃动。
```

按场景追加：

- 巨柱大殿：柱体不得弯曲或相互靠拢；人物始终保持微小尺度。
- 天阶队列：所有人物留在阶梯或桥面内，共同方向不变。
- 飞瀑：水流连续受重力下落，落点雾化，不遮蔽主体。
- 单人栈道：正好一人，始终背对镜头，可向远方缓步一至两步后停望，不回头、不走向镜头。
- 圆拱对称：轴线、圆心、平台和人物关系不得漂移。
- 骑兽：骑手与坐骑接触稳定，不分离、不增肢、不悬空滑行。
- 倒置天宫：建筑保持倒置，不旋转复位；瀑布仍按世界重力向下。

## 单图模板

```text
视频提示词

Timestamped prompts
- 0-[总时长]：远景/大全景深景深长镜头，[机位]，[主运镜]。首帧严格沿用参考图并写明[人物开始状态]；开头稳定建立，随后产生真实视差。人物完成[可见主动作]，[同伴延迟回应]，并在结尾进入[人物段尾状态]；画面中实际存在的云、银河、星星、树叶、瀑布、雾气、水面和衣摆按各自物理规律及不同频率持续运动。镜头减速停在[结束构图]。一镜到底，无切镜。

UI / Graphic layout
- 无字幕、无水印、无标题、无 logo。

Color / Lighting
- [色光模板]。

Music / SFX
- 0-[总时长]：[配乐]；[环境音]。

Dialogue / voice-over
- 无台词、无旁白、无明显口型动作；使用肢体交流。

Continuity / Negative constraints
- [通用负面约束 + 场景专用约束]。
```

## 多图模板

```text
视频提示词

Timestamped prompts
- 0-[切点1]：[图1对应场景与主运镜]；[人物开始状态 → 可见主动作 → 段尾状态]；[可见环境元素及分层动态]。
- [切点1]-[切点2]：硬切至[图2对应场景]，[主运镜]；重新声明人物并写出[开始状态 → 动作过程 → 段尾状态]。
- [切点2]-[总时长]：硬切至[图3对应场景]，[主运镜]；人物完成[可见动作]并自然收势；结尾减速收住。

UI / Graphic layout
- [全片统一 UI 规则]。

Color / Lighting
- [分段冷暖关系与每段光向]；说明硬切后的色调变化。

Music / SFX
- 0-[总时长]：[统一配乐]；在硬切点用音乐延音连接，不添加转场爆音。

Dialogue / voice-over
- [对白规则]。

Continuity / Negative constraints
- 每张图分别作为对应段首帧锚点；不同场景只在指定时间硬切，禁止场景混合、建筑互相继承和人物跨段串场；其余使用通用负面约束。
```
