# README 设计说明

## 目标

为 GitHub 仓库新增一份中文实用型 `README.md`，让首次访问者能快速理解、安装、调用和验证 `design-seedance-celestial-motion`。

## 内容结构

1. 项目名称、图标和一句话定位。
2. 适用场景与核心能力表。
3. 安装、更新和调用方式。
4. 单图、多图与动作增强示例。
5. 固定输出模块和稳定性原则。
6. 仓库目录和本地验证命令。

## 边界

- 中文为主，保留 Seedance、Timestamped prompts 等必要英文术语。
- 不添加不存在的截图、版本徽章、许可证或平台兼容性承诺。
- 安装路径使用 Codex 当前识别的 `~/.codex/skills/design-seedance-celestial-motion`。
- 示例只展示调用方式，不复制完整长提示词。

## 验收

- `README.md` 非空并包含简介、功能、安装、使用、输出结构、目录和验证章节。
- 仓库 URL、Skill 名称、测试命令和目录均可与当前项目对应。
- 原有动态契约测试继续通过。
