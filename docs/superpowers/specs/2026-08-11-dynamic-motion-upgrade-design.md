# Seedance 人物与环境动态升级设计

## 目标

升级 `design-seedance-celestial-motion`，使每个包含人物的分镜都具有可见、克制、符合景别的人物动作，并让画面中实际存在的云、银河、星星、树叶等元素持续自然运动，同时维持人物身份、建筑结构和空间连续性。

## 已确认的默认策略

- 人物采用混合动态：远景使用缓步、转肩、点头、抬手示意等稳定微动作；中近景可使用交谈姿态、递物、并肩行走、停步回应等明确关系动作。
- “聊天”默认只通过身体朝向、视线、手势和回应动作表达；无具体台词、无明显口型。
- 每个有人物的分镜必须写出人物开始状态、动作过程和段尾状态。衣摆、呼吸或站立不单独算作完整人物主动作。
- 画面中没有人物时不凭空添加人物。

## 环境动态契约

- 白云与云海：沿统一风向持续漂移，近层快、远层慢，并保留低频翻涌。
- 银河与星河：沿参考图原有走向缓慢流动，不旋转成漩涡，不改变天空构图。
- 星星：稀疏、错峰、轻微闪烁，禁止全屏同步频闪。
- 树叶、松针与树梢：随统一风向分层摆动；树干和粗枝保持刚性。
- 衣摆、长发、灯笼与帘幔：共享主风向，但以不同延迟和幅度响应。
- 瀑布、水面、雾气与反射继续遵守重力、流体、遮挡和视差规律。
- 只激活参考图中确实存在的元素，不擅自添加银河、星星、树木或瀑布。

## 文件边界

- `SKILL.md`：定义强制人物动作、景别分级、环境分层动态和检查清单。
- `references/motion-archetypes.md`：把静立型原型改成稳定的微动作或关系动作，并补充银河、星星、云和植被规则。
- `references/output-contract.md`：在变量、时间轴模板、单图/多图模板及负面约束中加入强制动作槽位。
- `references/example-cases.md`：把案例中的纯静立人物改为克制但可见的动作。
- `tests/check-dynamic-contract.sh`：机械检查四个文档是否包含关键动态契约且不退回纯静态默认。

## 基线失败

旧版行为测试出现以下问题：

1. 四人远景被写成“背对镜头静立”，负面约束甚至写“禁止人物走动”。
2. 夜景只写“银河与星空微弱闪烁”，没有银河沿既有轨迹流动，也没有星星错峰闪烁。
3. 三分镜中人物分别“相对站立”“并肩眺望”“仰望星河”，动作只有呼吸、衣摆或抬头。
4. 多场景使用“云雾匹配转场”“云雾遮幅转场”，与不同空间必须硬切的规则冲突。

## 验收标准

- 文档契约明确：有人物的每段至少一个可见主动作；衣摆、呼吸、静立不能替代人物动作。
- 远景和中近景动作库分开，默认肢体交流而非口型或对白。
- 白云、银河、星星、树叶四类动态均有正向写法和失败控制。
- 时间轴模板包含“开始状态 → 动作过程 → 段尾状态”。
- 所有原型与示例不再把“静立且只动衣摆”作为默认完整人物表现。
- 同一测试场景在加载升级版 Skill 后，输出满足人物动作、环境动态、硬切和稳定性要求。
